# 技能页：紧凑多列网格

## 原来的问题

每个 Skill 占一整行，右侧竖着排四个 `btn-secondary`（启用 / 系统级 / 查看 / 删除）。
容器只有 608px，卡片因此被拉得很窄又很高：

| | 旧 | 新 |
|---|---|---|
| 每行列数 | 1 | **3**（1522px 视口） |
| 单卡高度 | ~180–200px | **109px** |
| 一屏可见 | 4 条 | 8 条以上 |
| 操作区 | 4 个竖排全宽按钮 | 1 个开关 + 3 个 24px 图标 |

## 现在的结构

```
Skills                                                    (+)
点 +：导入文件 / 创建（粘贴）/ 打开本机目录 …

[全部 8][已启用 7][已关闭 1][系统级 6]            排序 [名称 ▾]

┌ 抖音解析  session 系统级            ●──┐  ┌ 多引擎搜索  session 系统级       ●──┐
│ 抖音无水印视频/图文解析 —— 短链/链接…    │  │ 多引擎聚合网页搜索（无需 Docker… │
│ 使用 6 次 · v2.0.0 · 10/19   📌 ✎ 🗑  │  │ 使用 15 次 · v2.0.0 · 10/19  📌 ✎ 🗑 │
└────────────────────────────────────┘  └──────────────────────────────────┘
```

- **网格**：`repeat(auto-fill, minmax(min(300px, 100%), 1fr))`，容器 1080px。
  3 列 × 338px，窗口变窄自动降为 2 列 / 1 列。
- **卡片**：标题行（名称 + 来源徽标 + 系统级 / 已关闭徽标 + 启用开关）、两行描述、
  底部元信息 + 三个图标动作。
- **描述**：`-webkit-line-clamp: 2`，超出省略；`title` 里保留完整文本。
- **动作**：📌 系统级（开时绿色 `is-on`）· ✎ 查看/编辑 · 🗑 删除；删除悬停转为错误色。
- **启用开关**：`role="switch"` + `aria-checked`，替代原来的整行文字按钮。

## 排序

右上角下拉，选择写入 `localStorage['iexa.skills.sort']`，重开应用仍保持：

| 值 | 顺序 |
|---|---|
| `name`（默认） | 名称，`localeCompare('zh-Hans-CN')` |
| `usage` | 使用次数从高到低，同值按名称 |
| `recent` | `updatedAt` 从新到旧 |
| `status` | 已启用在前，再按系统级，最后按名称 |

筛选（全部 / 已启用 / 已关闭 / 系统级）与排序独立，计数始终按全量统计。

## 顺带修掉的两处

1. **事件监听泄漏**：旧实现每渲染一次就给每张卡的 4 个按钮各绑一个监听器；
   每次操作都会整表重建，旧节点虽然被丢弃，但监听器随闭包一起滞留。
   现在只在 `#skillList` 上挂一个委托监听，按 `data-act` 分派。
2. **`enabled` 判定**：旧代码 `!(s && s.enabled)` 把「字段缺失」当成已启用；
   现在统一用 `s.enabled !== false`，与 API 的默认值一致。
3. **属性转义**：`escapeHtml()` 走 `textContent`，不会转义引号，不能直接拼进
   `title="…"`。新增 `skillAttr()` 处理 `& < > " '`，描述里带引号也不会截断属性。
