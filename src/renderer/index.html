关于 IEXA-WIN

        
IEXA-WIN 是 IEXA iOS/Android 应用的 Windows 桌面版本。

        
它把主流 AI 模型带进原生桌面体验，并支持真实 Shell、文件系统访问和网页浏览能力。

        
功能特性

        
    
          
  • 真实 Shell 访问（cmd.exe / bash）
    • 
          
  • 文件系统操作（读写、编辑）
    • 
          
  • 网页内容抓取
    • 
          
  • 跨会话持久记忆
    • 
          
  • 多模型：可配置多个 AI 配置档并随时切换
    • 
        

        
技术栈

        
基于 TypeScript、Node.js 和原生 Web 技术构建，由 Electron 封装为原生桌面体验。

        
诊断

        
导出运行指标、版本信息与设备环境（不含密钥），便于排查问题。
